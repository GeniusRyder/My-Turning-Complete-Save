# My-Turing-Complete-Save
我的图灵完备全通关存档，有多个版本的存档

目前有0.1059 Beta、2.1.292版本

0.1059 Beta为1.0最终版

2.0如果以后更新了应该也能使用，只要游戏的关卡没太大变化

注意：图灵完备更新后存档路径有变，解压缩时需解压到正确路径
